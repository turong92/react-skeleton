# UI · 움직임 용어 — 에이전트에게 화면을 말로 시킬 때

「좀 더 고급스럽게」 대신 **이름 있는 부품 · 움직임**으로 말하면 한 번에 맞게 나온다. 이 문서는 그 이름과 이 레포에서 대응하는 것, 움직임을 시키는 공식을 모은 팁이다(규칙이 아니다 — 쓸지는 프로젝트가 정한다).

## 시키는 공식: 무엇이 + 언제 + 어떻게 + 얼마나

> **카드가**(무엇이) **화면에 들어올 때**(언제) **아래에서 16px 올라오며 나타나고, 칸마다 0.06초씩 늦게**(어떻게) **0.3초 ease-out 으로**(얼마나). **모션 감소 설정이면 바로 보인다.**

- **언제(조건)**: 처음 그릴 때 · 화면에 들어올 때(스크롤) · 마우스를 올릴 때 · 누를 때 · 일이 끝났을 때. 조건이 없으면 에이전트가 늘 움직이게 만든다.
- **얼마나(속도)** — 흔한 기준:

  | 종류                           | 길이                          | 곡선                                 |
  | ------------------------------ | ----------------------------- | ------------------------------------ |
  | 작은 반응(누름 · 토글 · 체크)  | 0.1~0.2초                     | ease-out                             |
  | 들어오기(모달 · 토스트 · 카드) | 0.2~0.3초                     | ease-out(빠르게 시작, 끝에서 느려짐) |
  | 나가기                         | 들어오기보다 짧게(0.15~0.2초) | ease-in                              |
  | 큰 이동(화면 전환 · 펼침)      | 0.3~0.5초                     | ease-in-out                          |
  | 계속 도는 것(로딩 · 루프)      | 1~2초 한 바퀴                 | linear                               |

- **모션 감소**: `@media (prefers-reduced-motion: reduce)` 에서는 빼거나 투명도만 남긴다. 이 레포 부품(`Spinner` · `Skeleton` · `Progress` · `Switch` · `SectionCard` …)이 이미 그렇게 한다 — 새 움직임도 같이.

## UI 부품 이름

| 이름                        | 무엇                                   | 이 레포                                             |
| --------------------------- | -------------------------------------- | --------------------------------------------------- |
| 히어로 섹션                 | 첫 화면 큰 제목 · 설명 · 주 단추       | `@skeleton/marketing` `Hero`                        |
| CTA                         | 「시작하기」같은 주된 행동 단추        | `Button variant="primary"` · `CtaBand`              |
| 내비게이션 바 · 스티키 헤더 | 위 메뉴 줄, 스크롤해도 붙어 있음       | `AppShell`                                          |
| 사이드바 · 드로어           | 옆에 붙은 메뉴 · 옆에서 밀려 나오는 판 | 없음(필요하면 `Dialog` 위에서)                      |
| 카드 · 벤토 그리드          | 정보 묶음 상자, 크기 다른 상자 격자    | `Card` · `SectionCard` · `FeatureGrid`              |
| 모달 · 백드롭               | 화면 위 창과 뒤를 어둡게 덮는 막       | `Dialog` · `ConfirmDialog`                          |

| 탭 · 아코디언               | 갈라 보기 · 접고 펴기                  | `Tabs` · `SectionCard collapsible` · `FaqAccordion` |
| 캐러셀                      | 옆으로 넘기는 카드 줄                  | 없음(필요하면 화면에서)                             |
| 스켈레톤 로딩               | 내용 자리에 회색 틀                    | `Skeleton`                                          |
| 무한 스크롤 · 페이지네이션  | 끝에 닿으면 더 불러옴 · 쪽 번호        | `InfiniteList` · `Pagination`                       |
| 스테퍼                      | 단계 표시(1·2·3)                       | `Stepper`                                           |
| 배지 · 아바타               | 작은 상태 표시 · 프로필 동그라미       | `Badge` · `Avatar`                                  |
| 빈 상태                     | 내용이 없을 때 안내                    | `EmptyState`                                        |
| 반응형                      | 화면 폭마다 배치가 바뀜                | 부품 기본                                           |

## 원칙

- 한 화면에 **주된 움직임은 하나**. 여럿이 같이 움직이면 어디를 볼지 모른다.
- 축하 효과(컨페티)는 **첫 가입 · 첫 결제 같은 순간에만**. 매번이면 질린다.
- 폰 위주 화면에서 마우스 전용 효과(마그네틱 단추 · 커스텀 커서)는 의미가 없다. 패럴렉스 · 스크롤 스냅은 긴 목록에서 멀미를 부르니 아껴 쓴다.
- 반투명 유리(글래스모피즘)는 사진 위 글자 대비를 떨어뜨린다 — 쓰면 `tests/contrast.test.ts` 대비를 확인한다.
- 움직임은 `transform` · `opacity` 로만(레이아웃을 다시 계산하는 `top` · `width` 는 끊긴다).
- **모션 감소 설정이면 빼거나 줄인다.**
